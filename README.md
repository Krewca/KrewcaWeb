## 🛠️ Technologie & Design

* **HTML5 / Vanilla CSS3**: Čistý kód bez zbytečných těžkých frameworků pro maximální rychlost načítání.
* **Esports-Tech Estetika**: Tmavé pozadí s jemnou mřížkou, skleněným efektem (*glassmorphism*) a neonovými akcenty (Valorant Red `#ff4655` & Cyber Cyan `#00f0ff`).
* **Vanilla JavaScript (`script.js`)**:
  * Dynamický psací stroj (*Typewriter effect*) střídající různé profesní role.
  * Karusel profesní cesty s podporou myši, dotykového gesta (*drag & touch*) a nekonečným smyčkováním přes navigační šipky.
